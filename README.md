\# Sales Report Generator



Automated Python tool that generates a professional PDF sales report with charts and summary tables from an Excel file.



\## Features

\- Reads sales data from an Excel file

\- Calculates total sales, top-selling product, and category breakdown

\- Generates bar chart (sales by category) and line chart (monthly trend)

\- Exports a polished PDF report ready to share



\## Tech Stack

\- Python

\- pandas — data processing

\- matplotlib — charts

\- reportlab — PDF generation
